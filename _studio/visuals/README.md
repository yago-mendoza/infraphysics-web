# Visuals

Image references kept for their style, never for their subject. One folder, `articles/`, with a `STYLE.md` that names every file and says why it is there: styles the author would like for the site's article images (covers, figures). They are candidates and moods, not the current rule: the rule for what gets published is [pages/VISUAL.md](../../src/data/pages/VISUAL.md). When a style from here is adopted, VISUAL.md gains a register and the reference stays as its example. Images that go with tweets are not kept here: they sit beside their tweet file in `../twitter/` (bank, queue or posted), and there is no style base for them, on purpose.

Rules for a file here: WebP or JPEG, long side at most 1600 px, under a megabyte (a reference needs no more), named by what it shows (`<slug>.webp`), one line in the folder's `STYLE.md`. These are the one kind of image tracked in git; article masters never are (they live in `media/` and go to the CDN).
