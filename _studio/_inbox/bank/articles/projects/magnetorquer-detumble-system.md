# Magnetorquer Detumble System

Sistema de bobinas magnéticas que genera par contra el campo magnético terrestre para reducir el giro de una plataforma tras su liberación en órbita y estabilizar su actitud.

- **Subsistema:** ADCS (*Attitude Determination and Control System*)
- **BOM estimada:** ~30 USD
- **Demuestra:** sensórica, estimación de actitud, control embebido, actuación electromagnética y validación de un sistema ciberfísico.
- **Referencias mencionadas:** DTU-Sat 2, ZACube-1, Delfi-n3Xt, AAUSat II y St. Louis University.
