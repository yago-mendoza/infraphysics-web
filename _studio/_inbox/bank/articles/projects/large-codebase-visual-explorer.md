Author's choice: save this as a project idea.

[Rik Arends's demo](https://x.com/rikarends/status/2098710248164868534). Retrieved post text through FxTwitter on 2026-09-13: Arends describes a codebase explorer handling 2.5 million lines at 120 Hz and says the uploaded video is limited to 60 fps. Those are the author's reported figures; performance has not been reproduced and the video has not been inspected frame by frame.

Seed: build a visual codebase explorer inspired by this interaction and scale. Exact visual design, language, rendering stack and feature set remain open. A possible first experiment is to measure navigation responsiveness on a real repository before deciding how to display file structure and code relationships. This is a future project, not an existing personal achievement.
