# _add-ctx (shared)

Optional context for any pack, articles or tweets: hand-written, never touched by the generator, pasted after a pack when the job needs it. The leading underscore marks the two hand-written folders under `ai-ctx/` (this one and `tweets/_add-ctx/`) apart from the generated files beside them.

| File | What it is |
|---|---|
| `sources.md` | Favourite places to look things up on the internet (sites, podcasts with transcripts, archives), one line each with what it is good for. |

One line per entry, tags in brackets at the end, so `npm run find -- --tvb <text>` searches here too. Only what the author adds himself.
