# Queue

What is going out. One file per piece, `<date>-<slug>.md`, image beside it with the same base name, frontmatter as in `../README.md`: `kind` (post, thread, reply, quote, meme), `language`, `status: ready`, `target` (the url a reply or a quote answers), `source`. The body is the text as it will be posted, one paragraph per tweet for a thread; below a rule, the notes to self.

Before it leaves, one question, from `../STRATEGY.md`: *if someone sees only this and opens the profile, have I given them a reason to follow?* No other checklist: tweets follow no canon. Once posted, the file moves to `../posted/` with `status: posted` and the `posted:` link.
