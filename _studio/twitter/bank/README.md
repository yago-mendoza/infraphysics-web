# Bank

Reusable material with no date and no destination yet. What goes here:

- **Takes**: a position on a recurring topic (*SFT vs DPO*, *is there a wall*, *agents and MCP*), written as the one to three sentences that would be the reply, plus the longer version if it exists.
- **Prepared replies**: answers to questions that keep coming back in the niche, ready to adapt to the post that asks them.
- **One-liners and observations** waiting for the right conversation.
- **Memes and images with their caption**: the image beside the file with the same base name, the caption in the file, the note on when it fits.
- **Fragments of the site** worth quoting: a `{lift}` paragraph, a footnote with a source, a wikinote contrast, copied here with the link to the piece.

One file per item, `<slug>.md`, frontmatter as in `../README.md` (`kind`, `language`, `status: idea | ready`, `source`). When an item finds its destination it is copied to `../queue/` with a date and the target; the bank copy stays, because a good take gets used more than once, and the file notes each use.
