# quote-of-post

> Paste first, in order: `_format_ctx/ACCOUNT.md`, `_format_ctx/NO-TICS.md`, `../STRATEGY.md`, this file, `../queue/`. Optional after them: `_format_ctx/expressions-*.md`, `sentences.md`, `moves.md`, `avoid.md`, `_format_ctx/examples/`.

**Input:** someone else's post (text, author, link) and the author's reaction to it.

**Output:** three quote posts, each with a comment that transforms the original, in the language of the post. Under each one: what it adds. Under all three: which one you would send, and the profile test on it.

A quote only earns its place when the comment does something to the original: reframes it, supplies the datum it is missing, or contradicts it with evidence. A bare *this*, or a restatement of the post in other words, is not a quote post; if none of the three clear that bar, say the piece should be a reply instead and write it as one.

Build each as the strategy's *The reply* section says: concede the frame, then take it further than its author did.

The three vary by **what the comment does to the original**: one reframes it (the same facts, a different axis), one adds the missing number or the missing case, one contradicts it from experience. If a piece already in the queue is the better quote for this post, say so instead of inventing a third.
