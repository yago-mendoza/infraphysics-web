# post-from-idea

> Paste first, in order: `_format_ctx/ACCOUNT.md`, `_format_ctx/NO-TICS.md`, `../STRATEGY.md`, this file, `../queue/`. Optional after them: `_format_ctx/expressions-*.md`, `sentences.md`, `moves.md`, `avoid.md`, `_format_ctx/examples/`.

**Input:** an idea, an observation, a number, a bank item (`../../_inbox/bank/`) or a wikinote of the author's.

**Output:** three own posts, one to three sentences each (or an image caption if the input is an image), in the language the input is in. Under each one: what kind of reader it is for. Under all three: which one you would send, and the profile test on it.

The three vary by **the shape of the claim**: one that states the observation flat and lets it land, one built on the concrete number or case, one that compresses it into an image or an inversion. Same idea, three ways in.

Before writing, check the queue: if this idea is already sitting there in a better form, say so. If it is there in a worse form, say which of your three should replace it.

When the idea comes from a bank item or a wikinote, name the file or the note in a line at the end, so the piece can be traced back. When it comes from something published on the site, link the real page rather than describing it.
