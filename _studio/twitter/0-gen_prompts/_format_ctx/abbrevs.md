p.s. — post scriptum. Añadido final. Muy usable.
v.g. — verbi gratia. “Por ejemplo”. Bastante niche.
i.e. — id est. “Es decir”.
viz. — videlicet. “A saber / concretamente”. Muy buena si quieres tono antiguo-académico.
per se — “en sí mismo”.
ad hoc — diseñado específicamente para el caso.
afaict — as far as I can tell. Muy bueno en tech Twitter.
afaik — as far as I know.
tbf — to be fair.
tbh — to be honest. Menos intelectual.
fwiw — especialmente buena para sonar poco performativo.
tl;dr — resumen. Ya muy estándar.
kudos — reconocimiento / crédito. Más natural que “props” si quieres un tono algo culto.
aka — also known as.
