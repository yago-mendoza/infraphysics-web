An [[WA8fVNaT|agent]] whose tools include search, navigation, fetching or browser automation. A researcher who can use the Internet.
- The difference from a crawler is the goal. A crawler wants to traverse; it follows routes by rules. An agent wants to obtain something; of forty links on a page it can say "this is the only one worth opening". The agent loop applies unchanged: goal, observe, reason, choose an action, observe the result, repeat ([[AgL00p8Q|Agent Loop]]).
- Its tools are the stages of [[RBmlX4Ar|crawling]] used on demand: a search engine for candidates, [[JGc7uotQ|fetching]] for a page, [[rSBc7TP1|browser automation]] when the content or the action needs a real browser, an [[Ap8rTm3K|API]] when one exists.
- Crawler plus agent is a real combination: crawler behavior for coverage, agentic reasoning for selection. And a site can address it directly with an [[Lm8xKr3P|llms.txt]], the clean version for readers that are models. Text hidden to steer it is [[dSiDXsDk|spam]].

## Interactions

- [[RBmlX4Ar|crawling]] : : The crawler follows every road because it has no opinion about destinations; the web agent opens the one page that answers its question. Same fetch, same parse, opposite selection policy
