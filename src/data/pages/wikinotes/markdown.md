Markdown represents document structure with conventions that remain readable in plain text. A parser turns those conventions into a structured document or HTML. Extensions add expressive power, but their meaning then depends on the compiler that understands them.

In this site, source articles combine Markdown with explicit syntax for equations, concept links and editorial blocks. The [[E9olQ6Ox|compiler]] defines that local contract; portability requires preserving either the source syntax or a deliberate export of its meaning.
