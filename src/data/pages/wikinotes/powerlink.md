An industrial Ethernet historically associated with B&R (now part of ABB). It achieves deterministic cyclic communication over standard Ethernet hardware with a managing node that polls the others in a fixed schedule, avoiding collisions by time slots rather than by special silicon.
- One more member of the fragmented [[1pkzK8nT|industrial Ethernet]] family: each vendor ecosystem built its own solution to the same determinism problem, and a plant with machines from several origins inherits several of them ([[xHZIkyPb|determinism]]).
