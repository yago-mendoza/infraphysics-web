Command-line tool provided by a cloud/hosting platform for managing deployments and services. Every major platform has one:
- `wrangler` ([[Hp5nVw9C|Cloudflare]]), `vercel` (Vercel), `netlify` (Netlify), `firebase` (Firebase), `aws`/`sam` (AWS), `flyctl` (Fly.io)
- They abstract the platform's API into shell commands: [[Dx8yLn3F|deploy]], configure, manage databases, view logs
- The alternative is using the web dashboard, but CLIs are faster and scriptable
