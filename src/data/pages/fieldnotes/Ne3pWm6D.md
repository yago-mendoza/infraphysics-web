Serverless [[Pg6tRw2H|PostgreSQL]]. A managed Postgres service that scales to zero — when nobody's querying, you're not paying.
- Full PostgreSQL — same [[Sv2nKx8R|SQL]], same extensions (including [[Pv3kBx9D|pgvector]])
- Branching: create a copy of your database for development/testing, like a git branch for your data
- [[Vc3pLx8B|Vercel]]'s recommended Postgres provider — native integration
- Contrast with [[Sb7tRx5K|Supabase]]: Neon is just the database (Postgres). Supabase is database + auth + real-time + storage. Neon is leaner if you only need SQL.
