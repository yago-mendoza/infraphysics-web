**OpEx** (operating expenditure) es el gasto necesario para mantener una organización o un sistema funcionando durante el periodo corriente. Sueldos, energía, alquileres, soporte, reparaciones y muchas suscripciones se reconocen normalmente en la cuenta de resultados cuando se consumen.

- Sigue el uso y la operación más de cerca que una inversión inicial: pagar una instancia cloud, renovar soporte o sustituir una pieza ocurre mientras el sistema está produciendo.
- Puede ofrecer flexibilidad, porque permite escalar, renegociar o cancelar capacidad sin poseer el activo completo.
- También puede esconder acumulación. Una cuota pequeña por usuario, llamada o mes puede superar el coste de propiedad cuando crecen el volumen y el horizonte temporal.
- Reducir OpEx puede significar automatizar trabajo, consumir menos energía o necesitar menos soporte; también puede significar trasladar el coste a [[CapEx4Fn|CapEx]], a otro equipo o a un riesgo todavía no materializado.
- La clasificación depende del contrato y de las normas contables. Un servicio plurianual, una licencia o el desarrollo de software pueden contener componentes tratados de forma distinta.

OpEx suele negociarse cerca de las personas que viven la operación diaria. Eso hace visibles costes que una compra inicial puede ocultar: downtime, fricción de soporte, lock-in, formación, observabilidad y tiempo humano.
