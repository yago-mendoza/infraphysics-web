Cloud platform for deploying [[Bk9sTm2J|backend]] applications. Drop in your code ([[Wk6jPs2D|Node.js]], Python, Go, Rust, whatever), Railway provisions a server and runs it.
- Simpler than [[Aw2pDx6F|AWS]], more backend-focused than [[Vc3pLx8B|Vercel]]
- Persistent processes: your server runs 24/7, not [[Jn4xWp7B|serverless]]. Good for: websockets, background jobs, long-running tasks
- Built-in [[Pg6tRw2H|PostgreSQL]], Redis, [[Mq4sLn8W|MySQL]] (one click to provision)
- Use case: when you need a real server that [[Lk2rXj6D|Workers]] or [[Vf6kRm2D|Vercel Functions]] can't handle: heavy compute, persistent connections, full Node.js with filesystem access
