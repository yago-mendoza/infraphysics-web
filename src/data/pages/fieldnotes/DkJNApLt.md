Google's tool for monitoring and troubleshooting a website's presence in Google Search results. The [[Sx8mKr2Q|SEO]] operator's dashboard.
- Shows which queries bring users to your site, click-through rates, average position
- Index coverage: which pages are indexed, which are excluded, and why (crawl errors, noindex, redirects)
- Submit [[Sm9pLx3R|sitemaps]], request indexing of new/updated URLs
- Core Web Vitals report: page speed, interactivity, visual stability (real user data, not synthetic)
- Manual actions: alerts if Google penalizes your site for spam, cloaking, or other violations
- Not analytics (no session duration, no bounce rate, that's [[U99MuNPb|Google Analytics]]). Not server management (that's [[Ng9LJhY5|Google Cloud Console]])

## Interactions

- [[Sx8mKr2Q]] : : Search Console is the primary feedback loop for SEO: shows exactly how Google sees and ranks your pages
- [[Sm9pLx3R]] : : sitemaps are submitted and monitored through Search Console
