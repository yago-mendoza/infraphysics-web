Serverless Redis and Kafka. [[Ex5rTm9K|External API]]: your app calls Upstash via HTTP, it doesn't run inside your server.
- Redis-compatible: caching, rate limiting, session storage, pub/sub, all via REST API or native Redis protocol
- Designed for [[Jn4xWp7B|serverless]]: scales to zero, pay-per-request, no persistent connection needed (works over HTTP, ideal for [[Vf6kRm2D|Vercel Functions]] and [[Lk2rXj6D|Workers]])
- Also offers QStash (message queue) and Workflow (durable execution), overlaps with [[In7tWs3K|Inngest]]/[[Tr4pDx8L|Trigger.dev]] territory
