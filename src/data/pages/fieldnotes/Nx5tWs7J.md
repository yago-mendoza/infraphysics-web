Full-stack [[Rc4pBn9L|React]] framework. [[ISjyfjZ6|Frontend]] AND [[Bk9sTm2J|backend]] in one project — the whole stack.
- Server-Side Rendering (SSR): pages can render on the server before reaching the browser, better for SEO and initial load
- API Routes: backend endpoints defined in the same codebase, deployed as [[Vf6kRm2D|Vercel Functions]] ([[Jn4xWp7B|serverless]])
- Created by the [[Vc3pLx8B|Vercel]] team — deploying Next.js on Vercel is the path of least resistance
- Contrast with [[Vp8rBm5J|Vite]]: Vite is just a bundler/dev server for frontend. Next.js is the entire application — routing, SSR, API, build, deploy. Vite builds the dist/; Next.js IS the app.
- Contrast with [[As8kTm3F|Astro]]: Next.js is React-only and ships JS to the browser by default. Astro ships zero JS by default and supports multiple frameworks.
---
## Interactions
- [[Vp8rBm5J|Vite]] : : Vite is a bundler — it builds frontend assets. Next.js is a framework — it IS the application (frontend + backend + SSR + routing). You use Vite to build a React SPA; you use Next.js to build a full-stack app.
