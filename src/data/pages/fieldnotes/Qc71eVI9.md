Management dashboard for Google Workspace organizations — users, groups, devices, security, billing. The IT admin's cockpit for a corporate Google environment.
- User management: create/delete accounts, assign licenses (Gmail, Drive, Meet), reset passwords, enforce 2FA
- Device management: approve/wipe corporate phones and laptops, enforce screen lock policies
- Security: audit logs, login activity, suspicious activity alerts, data loss prevention (DLP) rules
- App management: enable/disable Google services per organizational unit, manage third-party SAML apps
- Not for managing servers ([[Ng9LJhY5|Google Cloud Console]]) or website SEO ([[DkJNApLt|Google Search Console]])
