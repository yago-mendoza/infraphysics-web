Roman aqueducts, TCP/IP, the circulatory system and Unix pipes solved the same problem without knowing about each other. Extend the essay to ML: preprocessing | tokenisation | embedding | attention | output as a Unix pipeline. Batch size is backpressure, the KV cache is buffering, gradient accumulation is flow control. The same concepts in a new substrate.
