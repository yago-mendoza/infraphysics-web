# Agents

One instruction file for every coding agent (Codex, Cursor, Copilot, Claude Code): read [CLAUDE.md](CLAUDE.md) and follow it. It is the project's automation rules, architecture and active gotchas; nothing here repeats it.

Where the rest lives, so an agent does not guess:

- **Writing content** (articles, wikinotes): the docs in `src/data/pages/` are the source. [pages/README.md](src/data/pages/README.md) for frontmatter and pipeline, [SYNTAX.md](src/data/pages/SYNTAX.md) for the custom markdown, [STYLE.md](src/data/pages/STYLE.md) for the hard rules (never negotiable), [VOICE.md](src/data/pages/VOICE.md) for how an article sounds, [VISUAL.md](src/data/pages/VISUAL.md) for images, and the README of the category being written. Wikinotes: [wikinotes/README.md](src/data/pages/wikinotes/README.md) and [wikinotes/STYLE.md](src/data/pages/wikinotes/STYLE.md). Tags and concepts: [pages/AGENTS.md](src/data/pages/AGENTS.md).
- **Reviewing an article**: the procedure is the skill in [.claude/skills/review-article/SKILL.md](.claude/skills/review-article/SKILL.md); an agent without skills can follow it as a checklist.
- **Ideas, saved tweets, Twitter strategy, the bank, the queue**: [_studio/README.md](_studio/README.md). Nothing under `_studio/` is compiled or served.
- **An AI outside this repo** (a browser chat) gets one file from `_studio/ai-ctx/`: the authoring docs concatenated per job, generated by `scripts/context-pack.js`. An in-editor agent reads the sources instead; the packs exist so there is never a hand-written copy of the docs.
- **Build and scripts**: [scripts/README.md](scripts/README.md). Run `npm run build` after editing any markdown under `src/data/pages/`.
