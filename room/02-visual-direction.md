# Visual direction — first hypothesis

## Desired feeling

Quiet confidence. Precision without sterility. A Spanish engineer's personal laboratory that could sit near Silicon Valley, but values understanding, density of thought, and meaningful connections more than looking fashionable.

The visual identity should make production feel possible. It should welcome a quick diagram, a hand-like sketch, an annotated image, or a rough model that has been clarified with AI. Visuals should feel authored and explanatory, never like generic stock imagery.

## Avoid

- cyberpunk and generic hacker aesthetics;
- purple glowing dashboards;
- 3D decoration without explanatory value;
- excessive cards, badges, controls, and customisation;
- a CV disguised as a portfolio;
- a page that feels like an app before it feels like a person.

## Explore

- a wide editorial canvas with generous horizontal breathing room;
- a strong typographic identity and restrained sans-serif body text;
- industrial / scientific cues used as structure: status, sequence, diagrams, annotations, not decoration;
- one functional accent colour rather than many category colours;
- small purposeful motion: a changing current focus, connected references, subtle transitions between content modes;
- tools shown as a quiet vertical stack of small artefacts, inspired by the reference site;
- a light palette with mineral, paper, graphite, and signal tones, then a carefully designed dark counterpart.
- a possible black / red / blue signal palette inspired by technical video graphics, used with restraint and developed into its own language;
- a "whiteboard" or visual reasoning layer for selected pieces: diagrams, arrows, annotations, and imperfect-but-clear explanatory drawings;
- a consistent visual grammar for series such as data centres, brains, systems, or materials, without turning every page into a poster;
- diagrams that improve comprehension and speed of publishing, rather than illustrations added merely to make pages look busy.

## Whiteboard hypothesis

The whole site should not literally look like a whiteboard. That would flatten the identity and make the interface feel like a theme. Instead, the site can be a refined editorial shell containing moments of visual reasoning: a diagram, a sketch, a red/blue system map, a margin annotation, or a small canvas embedded in an article.

Test this first on one rabbit-hole-style article. If the visual language makes the idea clearer and the author faster, it can become a signature system.

## Signature motif hypothesis

The strongest shared visual across the author's domains may be **flow under constraint**: a signal enters a system, branches, meets a bottleneck, changes state, and feeds back. This can read simultaneously as a control curve, industrial process, data pipeline, neural path, or mathematical function without depicting any one domain literally.

The home now contains an initial restrained system trace: thin paths, a feedback loop, and red/blue signal points. It should remain subordinate to the person and the work. If it becomes decorative noise, reduce it; if it creates instant recognition, extend it into article diagrams and section transitions.

## Engineering standard for the interface

The visual system should behave like good engineering:

- minimum sufficient structure;
- high signal-to-noise ratio;
- depth available on demand, not announced loudly;
- every element has a job;
- honest representation of the author's actual work;
- graceful failure and clear fallback states;
- no spectacle that suggests expertise the content has not earned.

The page should feel calm, spacious, exact, and quietly alive. A starfield, excessive glow, dense dashboard, or conspicuous “smart” graphic is a failure of this standard even if it looks impressive in isolation.
